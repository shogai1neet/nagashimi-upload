nagashimi-upload プライバシーポリシー

nagashimi-upload（以下「本ツール」）は、YouTube チャンネル「流し見ずんだもん」の運営者が自分のチャンネルを管理するためだけに使う個人用ツールです。本ツールにおける情報の扱いは次のとおりです。

使用する情報

本ツールは、YouTube API サービスを使い、運営者本人が許可した範囲で次の情報にアクセスします。

  • 運営者自身の YouTube チャンネルへの動画のアップロードと、その動画の情報（タイトル、説明、サムネイルなど）の設定
  • 運営者自身のチャンネルと動画の統計情報（再生回数など）の取得

情報の保存

Google のログインで得た認証情報（アクセストークン）と取得した統計情報は、運営者のパソコンの中にだけ保存します。外部のサーバーには保存しません。

第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。

運営者以外の利用

本ツールは運営者本人のみが利用します。運営者以外の方の Google アカウントや YouTube の情報を取得することはありません。

YouTube と Google について

本ツールは YouTube API サービスを利用しています。YouTube 利用規約 と Google のプライバシーポリシー が適用されます。

アクセスの取り消しと削除

本ツールに与えたアクセス権は、Google アカウントのセキュリティ設定ページ からいつでも取り消せます。取り消した場合、運営者のパソコンに保存した認証情報も削除します。

お問い合わせ

GitHub の Issues からご連絡ください。

English — Privacy Policy for nagashimi-upload

nagashimi-upload is a personal tool used only by the operator of the YouTube channel "流し見ずんだもん" to manage their own channel.

  • Information used: Using YouTube API Services, the tool uploads videos to the operator's own channel, sets video metadata (title, description, thumbnail), and retrieves statistics for the operator's own channel and videos, only within the scope the operator has authorized.
  • Storage: Authorization tokens and retrieved statistics are stored only on the operator's own computer, not on any external server.
  • Sharing: No information is provided, sold or shared with third parties.
  • Other users: The tool is used only by the operator and does not access any other person's Google or YouTube data.
  • The YouTube Terms of Service and the Google Privacy Policy apply.
  • Revocation and deletion: Access can be revoked at any time at https://myaccount.google.com/permissions. When access is revoked, the stored authorization data on the operator's computer is deleted.
  • Contact: GitHub Issues
